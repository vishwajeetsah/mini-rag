Python is a high-level, interpreted programming language known for its readable syntax. A Python list is an ordered, mutable collection written with square brackets, for example [1, 2, 3]. Lists support indexing, slicing, and methods like append() and pop(). A tuple is similar but immutable and written with parentheses. Dictionaries store key-value pairs in curly braces and provide fast lookups by key. Python uses indentation, not braces, to define blocks of code such as loops and functions. Functions are defined with the def keyword, and the language's standard library includes modules for files, dates, mathematics, and testing.
